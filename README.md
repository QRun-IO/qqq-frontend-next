# PR assets: resizable navigation

Screenshots for the resizable left navigation PR (mocked API, production build). `default` is the
256 px navigation, `widened` the widest it may be (480 px at 1440, 40% = 409 px at 1024). The
`grip-*` shots show the handle on hover and with keyboard focus. The full set (every layout, both
modes, both widths) comes from `QQQ_E2E_SCREENSHOT_DIR=... pnpm test:e2e tests/e2e/resizable-nav.spec.ts`.
