## Changes since RC7

- API specification Download and View controls remain fully visible and usable in narrow panels, including 320px phones. Labels wrap when needed; the wide desktop layout is preserved. Real specification download and keyboard new-tab behavior are covered in light/dark and touch workflows.
- Bounded LONG fields reject invalid integer text with a field error instead of throwing during range validation. Exact integer-string bounds retain precision beyond JavaScript's safe-number range. Optional blanks and existing required-field messages are preserved.
- A process unit test scopes its choice-label lookup to the read-only field under test, avoiding ambiguity when an editable field displays the same label. This changes no product behavior.
