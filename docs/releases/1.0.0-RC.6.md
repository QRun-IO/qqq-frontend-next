**Not published.** RC5 remains the latest published candidate. Final 1.0 remains on hold for owner application testing and renewed explicit approval.

## Changes since RC5

- Legacy Material icon names absent from the existing Next maps render using a pinned, locally bundled Material Icons font with 2,234 unique names.
- Existing Next Lucide mappings, widget-specific overrides, image priority, colors, sizes and layout are preserved. Unknown names retain generic fallback icons.
- The extra icon inventory loads only when needed. No external font service or new package dependency is required.
- Developer and agent guides explain icon resolution and limits. Accessibility regression coverage verifies that decorative glyph text does not enter option names.
