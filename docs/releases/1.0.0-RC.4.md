## Candidate scope since RC3

- PASSWORD fields honor explicit uppercase/lowercase metadata, with Unicode-aware cursor preservation. Ordinary passwords retain their entered case; masking and show/hide behavior are preserved.
- Report previews honor `omitExposedJoins` for new filter and column choices while retaining saved joined data and filter values. Reordering available columns preserves omitted columns in their saved positions.
- The report editor preserves existing joined filters, sorts, columns and widths when opening and accepting the dialog. Basic/Advanced switching, Cancel, host Save and reopening preserve the intended data. The omission setting restricts new choices; backend permissions remain authoritative.
- Developer and agent guides describe these configuration contracts. The original Next UI remains the visual reference.
