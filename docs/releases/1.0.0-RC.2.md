# Next UI 1.0.0-RC.2 — candidate preparation

**Not yet published.** This is the next stability milestone for application testing. Final 1.0 remains on hold pending explicit owner approval. RC1 remains unchanged.

## Changes since RC1

- Report previews support backend table variants consistently across query, count, statistics and full-result copy. Variant switches clear stale preview state and cannot let an old copy request overwrite the clipboard.
- Report previews honor query and count capabilities independently, including Refresh, and stop showing cached data/errors when a capability is removed.
- Report filter editors restore saved-view reset behavior and show active filters in column headers. Statistics and CSV checks compare results with independent SQL.
- Configured Google Drive folder selection replaces the placeholder, with backend metadata/CSP prerequisites and controlled-provider tests. Real-provider verification retains its documented external-service limitation.
- Script editing provides local QQQ helper, keyword and file-identifier suggestions, with keyboard/touch selection and native undo/redo behavior.
- Copy controls align with the form. Selected record sections retain the original Next full-width card and responsive field columns when metadata omits widths; explicit widths still take precedence.
- Pinned table selection cells expose the full checkbox touch target at every density.
- Child-record CSV export returns to the original Next header position with one working control. Export respects content visibility/permissions, and widget render failures can retry with fresh backend data.
