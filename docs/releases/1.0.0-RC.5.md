# Next UI 1.0.0-RC.5

Status: candidate preparation. RC4 remains the latest published version. Final 1.0 remains held for owner application testing and explicit approval. Existing RC versions are immutable.

## Changes since RC4

- Restored the original Next uniform table-row backgrounds, retaining selected-row highlighting, opaque pinned cells and application CSS hooks.
- Restored original record overview value typography and spacing, retaining metadata widths and the selected-section layout.
- `hidePreview` hides the read-only report summary preview while retaining the editing query. Sorting, Refresh, Cancel, OK and host Save/reopen preserve the intended behavior.
- Column menus fit the available viewport height and scroll when needed, keeping keyboard and pointer actions reachable in short windows. Normal-height styling is retained.
