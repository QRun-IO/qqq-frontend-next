# Next UI 1.0.0-RC.5

Release candidate for application testing. **Final 1.0 remains on hold for owner testing and explicit approval.** Earlier RCs remain immutable.

## Install

```xml
<dependency>
    <groupId>com.kingsrook.qqq</groupId>
    <artifactId>qqq-frontend-next</artifactId>
    <version>1.0.0-RC.5</version>
</dependency>
```

Override an older BOM-managed frontend version and select Next with `-Dqqq.javalin.frontend=next`. The JAR serves the UI at `/` alongside `/qqq/v1`; no Node server is required. If Maven cached an earlier missing-artifact result, retry with `-U`.

Container: `ghcr.io/qrun-io/qqq-frontend-next:1.0.0-RC.5` (linux/amd64 and linux/arm64). Its build-time backend origin is `http://host.docker.internal:8000`; use the Maven JAR or rebuild the image for a different origin.

## Changes since RC4

- Restored original Next uniform table backgrounds, retaining selection highlighting, pinned cells and application CSS hooks.
- Restored original record overview typography and spacing, retaining metadata widths and selected-section layout.
- Report `hidePreview` hides the read-only summary preview while keeping the editing query available.
- Disabling a saved report's pivot table now clears its stored definition when Save is pressed, correcting silent validation failure.
- Column menus fit short windows and scroll when needed, keeping keyboard and pointer actions reachable.
