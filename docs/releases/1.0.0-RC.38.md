# 1.0.0-RC.38 — prepared candidate

This candidate is not yet released. Merge and publication follow the compatible Core and Collaboration releases.

- Record file controls support previews, opening and downloading through the documented delivery APIs, including PDF previews.
- Script authoring includes the isolated TypeScript editor, server lifecycle actions and record hook controls.
- Process results support file delivery, PDF preview and ordered record lists through standard metadata.
- Record queries respect authorization-filtered pagination; record layouts preserve section metadata.
- The current permission editor and companion Tools workspace remain integrated.

The release uses the standard UI API and extension documents. Worker execution, storage configuration and printer/scanner qualification remain responsibilities of the respective QBits and host application. See [verification and release status](../QBIT-RELEASE-STATUS.md) and [known requirements](../QBIT-KNOWN-ISSUES.md).
